How a quote is taxed (engine rules, for the spec)

  1. If customer is tax exempt with a valid certificate → all tax = $0; certificate # printed on quote.
  2. Look up combined rate for the job-site ZIP (not billing address). No match → block send and show “ZIP not found, add rate”.
  3. Equipment & Material lines with tax code TPP → taxable at combined rate.
  4. Labor / Service / Subcontract lines → consult rule (state, job type, property class, line type). Taxable → same combined rate unless a state-specific labor rate is configured.
  5. Permit/Fee pass-throughs → not taxable by default (configurable per item).
  6. Manager may override the rate or a line's taxability with a reason; override is logged and printed as a footnote.
  7. Applied rates, rule IDs and table versions are frozen on the quote version. Quote PDF carries “Tax estimated from job-site ZIP; final tax determined at invoicing.”
